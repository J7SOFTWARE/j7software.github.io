Welcome to Tchiki Mail

Your inboxes, together in one friendly place.

Tchiki Mail is an ad-free Android email app designed to manage several mailboxes without jumping between apps. It combines everyday email tools with customizable appearance, message alerts, voice assistance and security options.

📬 One place for your mail

Check several email accounts, folders and messages from a single app.

✨ Your kind of design

Switch between the colorful Classic interface and the clean Material interface.

🔔 Stay informed

Receive new-message notifications and create special alerts for important senders.

🔒 Your personal space

Use secure account connections, app lock and optional screen-capture protection.

Android 9 or newerAndroid version requirement
No fixed account capDuring trial or Premium
32 languagesPhone language detected at first launch

How this guide works

Start with First launch, then follow Add your first account. The navigation lists every feature by topic. Use the search box to find a task instantly, and use Print / PDF to save a paper-friendly copy.

ⓘ
Note

This guide describes the functionality found in the supplied Android project, version 5.10.764 (build 764). Screens and available actions can differ slightly by account provider, Android version, device permissions and subscription status.

02 / 33Getting started

First launch & phone setup

Give notifications the best chance to arrive on time.

When you first open Tchiki Mail, the setup guide explains which Android settings can prevent mail checks in the background. It provides device-specific guidance for popular phone brands.

  1. Open Tchiki Mail and follow the welcome screens.
  2. Select your phone brand if prompted. You may also choose the general Android instructions.
  3. Allow notification permission when Android requests it, so the app can show new-message alerts.
  4. Review battery restrictions. Open Android Settings → Apps → Tchiki Mail → Battery, then choose an unrestricted or equivalent background setting if available.
  5. Complete the setup and continue to your first mailbox. You can choose the app’s appearance during onboarding.

Advice for specific phones

Xiaomi / MIUI / HyperOS

Allow Autostart when available and check battery/background restrictions. On some versions, locking the app in Recents can help.

Samsung

Check Background usage limits and add Tchiki Mail to Never sleeping apps if notifications are delayed.

Huawei / Honor

Review launch management and allow background activity.

OnePlus / other Android phones

Look for battery optimization settings and background activity permissions.

!
Important

Android controls actual background execution. A 5-minute sync setting does not guarantee that a message will appear exactly five minutes later; battery saving, connectivity and manufacturer restrictions can delay it.

Add your first email account

Gmail, Outlook, Microsoft 365 and standard mail servers.

From the home screen, choose Add account. You can also open Settings → Email accounts → Add account. The form detects common providers from the address you enter and may fill in server details for you.

  1. Enter your full email address.
  2. Follow the provider-specific sign-in instructions shown on screen.
  3. For standard mailboxes, enter your password or app password; review server details if needed.
  4. If available, tap Test connection to check access to your mail server.
  5. Give the account an optional display name and select its account color.
  6. If offered, choose the additional server folders to synchronize. The Inbox is synchronized automatically.
  7. Save the account, then allow the first synchronization to finish.

Which sign-in method should I use?

Google Gmail

Use an app password for IMAP/SMTP; the app does not provide Google OAuth sign-in.

Outlook / Hotmail / Live

Select Sign in with Microsoft. Authentication opens the Microsoft sign-in experience.

Microsoft 365 work or school

Use the Microsoft sign-in path if your domain is recognized as Microsoft 365.

Other IMAP / POP3 providers

Use detected settings or enter incoming/outgoing hosts, ports and SSL/TLS options manually.

✓
Security tip

Never enter your regular Google account password into the Gmail IMAP password field. Google accounts typically require 2-Step Verification and a separately generated app password for this setup.

Gmail: step-by-step

Use a dedicated password for Tchiki Mail.

Gmail connects through IMAP for incoming mail and SMTP for outgoing mail. Tchiki Mail’s Gmail setup screen includes app-password instructions.

  1. On your Google Account, enable 2-Step Verification if you have not already.
  2. In Google Account security settings, open App passwords if that feature is available for your account.
  3. Generate an app password for the email client and copy it.
  4. In Tchiki Mail choose Add account and enter the full Gmail address.
  5. Paste the generated app password into the password field.
  6. Keep the detected server settings, select Test connection, then save.

Outlook & Microsoft 365

Sign in with your Microsoft account.

Outlook.com, Hotmail, Live and supported Microsoft 365 accounts use Microsoft OAuth2 and Microsoft Graph. Normally, you do not have to enter an SMTP or IMAP password for these accounts.

  1. Open Add account and enter the Microsoft email address.
  2. Choose Sign in with Microsoft when prompted.
  3. Complete sign-in on the Microsoft page, including any multi-factor verification required by your organization.
  4. Return to Tchiki Mail and save the account after authorization.
  5. Wait for the first sync, then open the account’s Inbox.

When sign-in needs attention

If the app shows a sign-in or authorization problem, go to Email accounts → Edit account and choose Sign in again with Microsoft when offered. Organization policies or missing consent can prevent some work accounts from connecting.

✦
Good to know

If you are adding a business domain but it is not a Microsoft 365 mailbox, dismiss the corporate-provider suggestion and configure it manually.

Understand the home screen

Jump between accounts, search or write a message.

The home screen shows your email accounts as individual cards, with color identification and unread indicators. It also provides shortcuts for searching, synchronizing, composing and opening Settings.

  1. Tap an account card to open its folders.
  2. Choose Inbox for incoming messages, or select another folder.
  3. Use the search icon to find messages across the locally stored mailboxes; search matches sender, subject and preview.
  4. Choose Compose to create an email; you can choose the From account.
  5. Use the synchronization action to request a mail check, or open Settings to customize the app.
✦
Good to know

Touch and hold an account card for about 2.5 seconds to toggle notifications for that account, when the shortcut is available. The app displays an onboarding hint for this gesture.

Android home-screen inbox widget

See the latest unread mail without opening the app.

Tchiki Mail includes an Android home-screen widget. It shows the total unread-message count and a list of up to five recent unread messages across accounts, including sender, subject, time and mailbox name when available. Tapping a message opens that email in Tchiki Mail.

  1. Touch and hold an empty area of your phone’s home screen.
  2. Choose Widgets from your Android launcher.
  3. Find Tchiki Mail and add its inbox widget to the home screen.
  4. Tap a listed message to open it in the app; tap the widget background to open Tchiki Mail.
  5. If the widget looks outdated, open Tchiki Mail and synchronize. Background refresh also depends on Android restrictions.
ⓘ
Note

The widget lists recent unread messages from the local database, not the entire inbox. It is refreshed after supported synchronization events; it is not a real-time push-mail feed.

Manage multiple accounts

Edit, reorder and organize your mailboxes.

Open Settings → Email accounts to see every account. Select an account to edit its details or remove one you no longer use.

  1. Open Email accounts from Settings.
  2. Choose Edit account to modify the account display name, password or connection settings where supported.
  3. Use Sort accounts to change their order.
  4. To add another mailbox, select Add account.
  5. To remove an account, use its delete action and confirm the warning.
!
Important

Removing an account deletes its locally stored emails from the app. Keep any important material on the mail server or export it separately before removing the account.

Account colors & active accounts

Assign each mailbox its own color to make it easier to recognize. The trial and Premium plans have no fixed account-count limit in the current app code. After the trial, the free version can keep 2 accounts active; additional configured accounts may remain saved but inactive. You may be prompted to choose which two remain active. A 24-hour cooldown can apply before changing that free-plan selection again. The practical number of accounts depends on device performance, available storage and mail-provider behavior.

Read an email safely

See rich content while staying in control.

Open any message to see its sender, recipients, subject, message body and available attachments. HTML emails are displayed in an embedded viewer; plain-text emails are also supported.

Images & links

For privacy, remote images and other externally loaded content can be blocked. When an email offers a Load images banner, choose it only if you trust the sender. The app can identify known tracking-pixel patterns. Links are handled through options such as Copy link and Open in browser.

Quick actions

↩ Reply

Write a response to the sender.

⇢ Forward

Send the original message to another person.

✉ Quick reply

Choose from short prepared answers such as “Thanks!” or “Noted” and confirm before sending.

✓ Read receipt

If the sender asks for a receipt, choose whether to send a confirmation.

ⓘ
Note

A read receipt confirms that a recipient’s mail software reported opening the email; not all providers or recipients send these. A message being sent is not the same as a receipt being received.

Attachments & attached emails

Open, save and share the files you need.

A paperclip indicates an attachment. Open the email and scroll to its attachment area. Depending on file type and Android’s available apps, you can open the file or save it to Downloads.

  1. Open the message with a paperclip.
  2. Find the attached file under the message.
  3. Choose Open to use a compatible viewer or Save to Downloads to keep a copy.
  4. If the file cannot be opened, install a compatible viewer or save it and open it from your files app.

Special attachment types

✉ .eml email files

Tchiki Mail can show attached email messages inside the app, including nested email content and attachments.

▦ .ics invitations

Calendar invitation files can be passed to a compatible application.

♙ .vcf contacts

Contact-card files can be opened using a compatible contacts app.

▤ Other files

PDFs, images and documents depend on Android’s available file handlers.

✓
Security tip

Do not open unexpected attachments or run executable files from unknown senders. A sender address alone does not guarantee a message is trustworthy.

Write & send a message

A rich composer with familiar email tools.

Tap Compose from the home screen or an account folder. The composer supports recipient suggestions, multiple recipients, formatted text and attached files.

  1. Select the From account if you use several mailboxes.
  2. Enter one or more addresses in To (separate multiple recipients with a comma or space).

  5. Use the formatting tools for emphasis, text color, highlighting, links or message background where offered.
  6. Tap Add attachment to include files, if needed.
  7. Optionally enable Request read receipt, then tap Send.

Recipient suggestions & saved addresses

Type addresses faster with the app’s own recipient history.

While composing an email, Tchiki Mail offers contact suggestions in the To, CC and BCC fields. Addresses used when sending messages are saved in an in-app contact history so they can be suggested again.

  1. Create a new message and tap the To field.
  2. Begin typing a name or email address. If you leave the field empty, the app may display saved addresses.
  3. Choose a suggestion to insert that email address.
  4. To remove a saved address from future suggestions, use its Delete action in the suggestion list and confirm.
  5. You can also use suggestions while filling in CC and BCC.
ⓘ
Note

This is an in-app saved-recipient list; the current code does not establish that the feature imports the entire Android Contacts address book. Deleting a suggested address does not delete emails already sent to that recipient.

Drafts & sending while offline

Keep writing even when the network is unavailable.

Use Write and save or the relevant back/save action to keep an unfinished email as a draft. Drafts can be opened later from the account’s Drafts folder.

  1. Start a message, enter some content and choose to save it as a draft.
  2. Open the account’s Drafts folder when you are ready to continue.
  3. Select the draft, edit it and send when finished.

Offline sending queue

If you try to send a message without network access, Tchiki Mail can place it into a sending queue and display a confirmation explaining that it will be sent when connectivity returns. The app also has handling for failed or uncertain sends.

!
Important

A queued message is not yet delivered. Reconnect and allow background work to run. If an error appears, verify the delivery status before manually resending to avoid duplicates.

Search your mail

Find messages by people, subjects or content.

Tap the Search icon from the main screen. Search covers messages already saved in the local app database across accounts. It matches subject, sender name, sender email address and the short message preview (snippet). It does not perform a full-text search of complete email bodies or search messages that only exist on the server. It returns up to the 200 newest matching messages.

  1. Open Search.
  2. Enter at least two characters from a sender name, sender address, subject or visible message preview.
  3. Review the matching results and tap an email to open it.
  4. If you get no results, try a shorter term or synchronize the relevant mailbox first. Words that appear only deep inside a message body will not match.

Useful searches

invoice

Find messages mentioning invoices.

alice@example.com

Find mail related to a known email address.

meeting

Look for a keyword in message subjects or available text.

ⓘ
Note

Search does not scan the complete body of saved emails, only their locally stored subject, sender and preview. Messages not downloaded into the app will not appear.

Automatic message filters

Sort incoming mail without doing it by hand.

Open Settings → Message filters. A standard move filter checks incoming mail and moves matching messages to a folder you choose.

  1. Choose Add filter.
  2. Select the email account the rule should apply to.
  3. Choose a condition: Sender email address, Sender domain, or Subject contains text.
  4. Enter the value to match, such as news@example.com or invoice.
  5. Choose a destination: Spam, Trash, Inbox, Sent, or a named custom folder.
  6. Save the rule, then leave it Enabled.

Examples

Move newsletters

Condition: sender domain → newsletter.example. Destination: your Newsletters folder.

Sort invoices

Condition: subject contains → invoice. Destination: your accounting folder.

Train your spam workflow

Move a message to Spam from the message view; the app can create or maintain automatic spam filtering behavior.

ⓘ
Note

After the trial, the free plan normally permits creation of one standard filter and one separate Message Watch rule. If more rules were created during trial or Premium, the extra rules can remain stored but only one of each type may be enabled. Disabling your only rule does not necessarily unlock creation of another; edit or delete it first.

Message Watch: important-email alerts

Give selected senders their own attention-grabbing sound.

In Settings → Message filters, use Message watch to create special alert rules. These are different from move filters: they identify matching mail for additional notifications and sounds.

  1. Open Message filters and choose Message watch.
  2. Select the account to monitor.
  3. Pick Sender email address, Sender domain, or Subject contains text.
  4. Enter the matching value.
  5. Choose an alert sound: Ping, Notification, Alarm, Ringtone or a custom sound.
  6. Save and enable the watch rule.

Good situations for Message Watch

Family & friends

Hear a distinct alert when a specific person contacts you.

Work-critical messages

Watch a team domain or a project keyword.

Deliveries & appointments

Use a matching subject phrase to notice time-sensitive notices.

ⓘ
Note

The free plan normally allows one Message Watch rule to be created; after an expired trial, only one existing watch rule may be active at a time. Sound playback also depends on Android notification permission, sound settings and Do Not Disturb.

Notifications & quick actions

Handle new mail without opening every message.

Tchiki Mail shows Android notifications for new messages and uses separate channels for message-watch alerts, sign-in problems, updates and background synchronization. Available notification actions include Reply, Mark as read and Archive.

Manage notifications

  1. Open Android Settings → Apps → Tchiki Mail → Notifications to allow alerts and manage channels.
  2. On the Tchiki Mail home screen, touch and hold an account card for about 2.5 seconds to change that account’s notification state if the shortcut is available.
  3. For priority messages, set up a Message watch rule and select a distinct alert sound.
  4. If background notifications are delayed, review battery limits and the sync interval.

Notification reply

Some notifications offer a reply field directly from Android’s notification shade. Confirm your response; if sending does not complete, review the corresponding message before retrying.

ⓘ
Note

Mail checks occur by synchronization, not an always-on provider push connection. Notification delivery timing can vary with the device and account provider.

  1. Open Settings → Accessibility.

Contrast

Different voices

Control who can view your messages.

Back up & restore your settings

Move your configuration to a new install.

Under Settings → Backup & Restore, export configuration to a JSON file or import a previously saved backup. Backups include settings, accounts and filters; they are not a complete archive of your email messages.

Export a backup

  1. Open Settings → Backup & Restore → Export Backup.
  2. Choose whether to include account passwords. The default is not to include them.
  3. If including passwords, create and repeat a backup password of at least 8 characters.
  4. Choose a location and file name using Android’s file picker.
  5. Store the JSON file safely and retain the backup password somewhere secure.

Restore a backup

  1. Select Restore from Backup.
  2. Choose your saved JSON backup.
  3. If it contains encrypted passwords, provide the original backup password, or choose to import without passwords.
  4. Review the restoration summary. You may be asked to restart Tchiki Mail and sign in again to some accounts.
✓
Security tip

Microsoft OAuth tokens are not included in the password backup. You will need to sign in to Microsoft accounts again. Password-protected backup files should be treated as sensitive. Export is a full-access feature; restoring may also require account sign-in.

Language & interface text

Use the language you are most comfortable with.

Tchiki Mail includes 32 selectable languages. On the first launch, it detects your phone’s language and uses English as a fallback if that language is unavailable. The detected language is then saved. Later changes to the phone’s language do not automatically override your saved selection.

  1. Open Settings → Language.
  2. Choose a language from the list of supported languages.
  3. The app saves your choice and attempts to restart so the interface uses the new language.
  4. To match a newly changed phone language, select that language manually. There is no dedicated Automatic/System option in the current language picker.

Language and voice

The app’s message labels, prompts and errors use the selected interface language where translations are available. Voice readout also attempts to follow the language, but installed TTS voices are provided by Android or a third-party speech engine.

ⓘ
Note

The language of emails you receive is not translated automatically by the interface language setting.

Troubleshooting & common questions

Solutions to the issues most users encounter.

Try the relevant steps below. If a provider reports a server-specific error, review that provider’s account settings and service status as well.

My Gmail account will not connect.⌄
Check that you are using a Google app password rather than your normal sign-in password. Verify IMAP access and 2-Step Verification requirements, then run Test connection. See Gmail setup.
Microsoft sign-in keeps asking me to log in.⌄
Open Settings → Email accounts → Edit account and use the Microsoft sign-in/re-authentication option. Your organization may restrict third-party apps. Check your connection and complete any multi-factor prompt.
I do not receive notifications when the screen is off.⌄
Verify Android notification permission; review the selected sync interval and battery restrictions; allow background activity. Xiaomi, Samsung and Huawei may require additional permissions. See phone setup and notifications.
Messages are not synchronizing.⌄
Pull down in the mailbox or tap Sync now. Check internet access, credentials, server availability and Android battery settings. If an individual account shows an error, edit that account rather than deleting everything.
My message says it is queued. Was it sent?⌄
Not yet. A queued message is waiting for connectivity or processing. Reconnect, allow the app to sync, then verify its status before attempting to resend.
The app cannot send an attachment.⌄
Verify that the file is still available and readable. A large message may exceed your provider’s outgoing limit. Remove or reduce attachments and try again.
Images are missing from a message.⌄
The app may be blocking remote images for privacy. Use the Load images option only for trusted mail. Some messages refer to images that were not actually included by the sender.
An attached file will not open.⌄
Choose Save to Downloads, then open it using Android Files or install a compatible viewer. Tchiki Mail has its own viewer for supported .eml attached email files.
My email disappeared after I moved or deleted it.⌄
Check Trash, Spam, Sent or the destination folder. Moves and deletions can sync to the server, so the message might also have changed location in other mail clients.
Why do I see only two active accounts?⌄
Your 30-day trial may have ended. The free plan allows two active accounts. Open Settings → Email accounts to manage active accounts, or see plan limits.
Can I change the application language?⌄
Yes. Open Settings → Language and select one of the supported languages. The app chooses the phone language at first launch but does not currently offer a persistent Auto/System entry in the picker. Text-to-speech voices depend on the Android speech engine.
Why does the voice feature need two taps?⌄
In Reading mode, the first tap reads an element aloud and the second tap within approximately three seconds activates it. Turn Reading off to use standard controls.
What if I forget my backup password?⌄
Encrypted account passwords inside that JSON backup cannot be recovered without the backup password. You can import without passwords and enter mailbox credentials again.
Does a backup include all my email messages?⌄
No. The documented backup exports configuration such as accounts, filters and settings. It is not a complete archive of your downloaded or server messages.
Does search look inside the complete text of every email?⌄
No. Search matches locally saved subject, sender and the short message preview. It does not index whole message bodies or perform live server search. Results are capped at 200 matches.
I cannot find an option mentioned here.⌄
Some options require Premium or an active trial, some depend on your phone’s capabilities, and some appear only for specific account types or folders. Check the relevant section of this guide.
